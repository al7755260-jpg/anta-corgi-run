# 汪汪向前冲 · ANTA CORGI RUN

使用提供的安踏上海总部建筑与柯基模型制作的像素跑酷游戏。

**在线试玩：https://al7755260-jpg.github.io/anta-corgi-run/**

打开链接即可体验，手机与电脑均无需安装。点击“开始跑酷”后自动奔跑并播放音乐。首次进入需加载建筑、角色与音乐资源。

GitHub 仓库：https://github.com/al7755260-jpg/anta-corgi-run

## 开始玩

双击 `启动游戏.cmd`。它在本机启动服务并打开 http://127.0.0.1:5179 。当前电脑已安装 Node.js；换电脑使用时需要 Node.js 20.19+。

也可在此目录运行 `node server.mjs`，然后打开上述地址。关闭游戏网页不会结束本地服务；需要停止时运行 `停止游戏.cmd`。服务仅监听本机，不会上传模型。

## 操作

- 点击“开始跑酷”立即奔跑，无倒计时。自动前进，← / → 或 A / D 左右换道。宽路由青色、蓝色、珊瑚红三道及连续白线明确标出；白线与实际换道中心对应，窄桥会收束成单道。
- 空格、↑ 或 W 跳跃；↓ 或 S 下蹲跑步穿过高横杆，动作持续约 0.95 秒。
- 跑动时鼠标拖动可环视，滚轮缩放；镜头跟随狗狗移动。R、双击画面或右上角相机按钮回到柯基身后。
- P / Esc 暂停。碰撞消耗一颗爱心；三颗用完可从最近检查点继续。被撞到的运动器材会弹飞或翻倒，落地后淡出；最后一次碰撞先展示约 0.8 秒动效，再出现继续界面。受伤后的短暂无敌期间仍有撞击反馈，但不重复扣血。
- 点击开始后默认播放背景音乐；右上角喇叭同时控制音乐和音效，并记住静音选择。暂停、查看地图或切到后台时音乐暂停，继续游戏后接着播放。
- 障碍包含哑铃、健身跳箱、训练跨栏和紫色高横杆；组合占据不同跑道，保留可躲避的路线。哑铃和跨栏可跳过，高横杆可下蹲通过。
- 收集金色爪印币加分，连续收集逐步提升至 4 倍分数。低位红心可直接跑过拾取，恢复 1 颗生命，上限为 3 颗。
- 手机左侧为跟手方向摇杆：拖动时实时连续横移，松手吸附最近跑道并保持；默认开启跟手，轻推小幅移动、大幅拖动快速横移；右侧为独立跳跃和下蹲按钮。点按跳跃立即起跳；下蹲短按约 0.95 秒、长按持续低身跑动。可以一边换道一边跳跃或下蹲。
- “自由漫游”忽略障碍伤害，沿同一条路线慢跑；拖动画面停下环视，滚轮缩放，可回到柯基视角。

## 路线与风格

一条约 1003 米的连续建筑巡游路线，全程没有关卡选择和场景传送。路线从入口大楼梯进入，绕行双环中庭与建筑连廊，经运动升降台抵达上层露台，再沿原建筑回到入口。西侧岔口沿回廊直行，移除了原先离开主体建筑的滨水折返和外围长距离绕行。露台尽端折返，升降台真实沿高度移动，狗狗在升降途中转向即将离开的出口；地点栏只标记沿途建筑位置。

建筑、柯基来自用户提供的实际模型。清晰像素风以蓝白建筑、亮蓝玻璃、青柠绿景观、珊瑚红与青色跑道呼应封面；使用分层卡通阴影、深蓝轮廓、有限色阶和中文点阵字体。普通桌面窗口按实际 CSS 像素绘制（1280×720 窗口对应 1280×720 场景），大屏最高 1920×1200，不再把场景压到 180–270 像素高放大。原模型几何、UV 和贴图分辨率保留，远处纹理使用 mipmap 降低闪烁；没有全屏模糊或景深。无人物 NPC。新增运动跑道、哑铃、健身跳箱、训练跨栏、高横杆、收集物和运动升降台。

彩色终点门架、哑铃与健身跳箱由 ImageGen 制作参考图，再经 Rodin 生成真实 3D 模型。游戏使用保留造型与 UV 的独立优化 GLB，门架文字叠加在模型的牌面上。原始模型保存在完整项目的 `design/source-models/`；参考图、提示词及三个生成页面的链接记录在 `design/rodin-concepts/generation-record.json`。

原建筑模型主要包含外观、公共平台与景观通道；本版没有虚构未建模的办公室内装。升降台与跑道连接桥是为连续游玩新增的游戏设施，不代表原建筑的实际施工设计。

## 文件

- `dist/`：已构建的离线静态网页和模型资源，不需要 npm 安装即可由服务启动。
- `src/`、`index.html`：可编辑源码。
- `public/assets/`：优化后的真实建筑/柯基 GLB、三个 Rodin 运动器材模型、像素封面、字体和背景音乐。
- `design/`：仅存在本地完整项目中，保存像素视觉规范、参考图、BGM 来源与 Rodin 原始模型、生成记录；不上传 GitHub，游玩 ZIP 使用优化后的副本。
- `licenses/`：Fusion Pixel 字体 OFL 许可。

原始 `.blend`、ZIP、绑定和源贴图均保留在用户原位置，没有回写修改。网页副本做了网格与材质优化，不能替代源模型作为建筑精度文件。

## 开发

`npm ci` 安装锁定依赖，`npm run dev` 使用 5178 开发端口；`npm run build` 重新生成 dist。

推送到 GitHub 的 `main` 分支后，GitHub Actions 自动构建并发布 Pages。构建使用相对资源路径，也支持其他静态网站的子目录部署。GitHub 仓库仅包含游戏源码、网页使用的优化资源和部署配置。

Three.js / three-mesh-bvh，Vite。真实运行由本地浏览器 WebGL 完成。背景音乐与音效在开始游戏的点击操作后播放。

## 穿模修正

实际采样统计约 85.3% 的总路线可三道换道；总长包含约 90 米升降台垂直行程。扣除升降台后约 93.7% 的行走路线支持三道，局部连接口保留短距离安全收束。全程设置 37 组障碍行、69 个障碍；提速后的最短行间距为 17 米。

常规跑速为 9.5–14 米/秒，按路程逐步加速；窄道 7.4 米/秒、升降台 10 米/秒、漫游 5.5 米/秒。升降台在跑酷和漫游模式下均使用加快后的速度。

入口改为沿实际弧形大楼梯行进；中庭、露台和建筑连廊路线按建筑实体重新布线。宽路可换道，窄路自动居中并减速，低净空处限制跳跃。柯基高度调整为约 0.76 米（比上一版小约 16%），按骨骼姿态实时校正脚底，并随坡面倾斜。新增桥的两处接入口仅在网页副本的栏杆上留出开口，原始建筑文件保持不变。路线已做每 0.1 米、多横向位置和不同跳跃高度的几何采样检查；同时完成浏览器加速连续巡检，五个区域到达终点。

露台往返段共用重复位置的跑道几何，避免两层跑道重叠闪烁；跑道表面抬升到建筑地面上方，修正露台地面交叉显露的问题。撞飞道具按当前坡面校正落点，避免落地后陷入斜坡。


## 柯基动作

使用原始 Rigify 四肢 IK 控制器制作 Run、Idle、Jump、Slide 四段动画，烘焙至原有 43 骨骼的网页骨架；保留原网格、蒙皮、UV 和贴图。Run 为约 0.667 秒循环，含错相落脚、蹬伸收腿、躯干重心变化及头耳尾跟随；在随跑速提高步频的基础上，额外加快 25%。

Slide 是约 0.667 秒的低身跑步循环：四腿交替弯曲蹬地，压低躯干和头部，耳朵、尾巴跟随摆动，身体总高度降低约 20%。动作通过骨骼制作，没有缩放压扁网格。进入下蹲与恢复正常奔跑时平滑混合，脚底按当前坡面校正。可编辑的 `柯基_奔跑动画.blend`、跑步预览和 `柯基_下蹲跑步循环.gif` 位于项目的上级交付目录。

## 背景音乐

已接入用户提供的《汪汪向前冲 · Pixel Paw Sprint》音乐。从用户手动下载的 MP4 直接复制完整 120 秒 AAC 立体声音轨为 `assets/pixel-paw-sprint.m4a`，没有重新压缩音频。游戏循环播放，音乐音量设为 24%，保留收集、跳跃和碰撞音效；新一轮从头播放，暂停后继续则保留位置。完整项目的 `design/bgm-brief.md` 记录创作与文件来源。
